# Hot Beans Web Development Website

A multi-page website developed using HTML, CSS and JavaScript for a fictional web development company called Hot Beans.

The website provides information about the company, introduces its development team, advertises job opportunities and allows prospective developers to explore careers and training opportunities.

## Features

The website includes:

- Company information
- Meet the Team section
- Web development job listings
- Individual job pages
- Job application pages
- Web development course information
- Contact page
- Frequently asked questions
- Multi-page navigation

## Careers

The website includes a dedicated careers section where users can browse available web development positions.

Individual pages provide additional information about different roles, with application pages allowing users to progress through a simulated recruitment process.

## Web Development Courses

A training section provides information about web development courses for users interested in developing the skills required to enter the industry.

This complements the recruitment section by providing a pathway for users who may not yet meet the requirements for the advertised positions.

## Company Information

Additional pages provide information about Hot Beans and its fictional development team.

The website includes:

- About Us
- Meet the Team
- Contact
- FAQ

These pages were designed to create a more complete company website rather than a single-page project.

## How to Run

No installation is required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The website will run locally in the browser.

## Project Purpose

This project was developed to practise designing and building a complete multi-page website using front-end web technologies.

It provided experience creating page layouts, navigation, recruitment content and interactive website elements while organising multiple pages into a consistent website.
